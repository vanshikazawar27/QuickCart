# 🛒 QuickCart – Simple E-Commerce Website

QuickCart is an open-source **e-commerce frontend** built with **Next.js and Tailwind CSS**.  
It focuses on delivering a fast, responsive, and easily customizable shopping experience.

---

## ✨ Features

- ⚡ Built with **Next.js** for high performance and SEO  
- 🎨 Styled using **Tailwind CSS**  
- 📱 Fully responsive design  
- 🧩 Reusable and modular UI components  
- 🔧 Easily customizable layouts and color themes  
- 🚀 Clean and modern user interface  

---

## 🛠 Tech Stack

- **Framework:** Next.js  
- **Styling:** Tailwind CSS  
- **Language:** JavaScript
